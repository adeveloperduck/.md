# Audio Files Setup

To add audio to your website:

1. **Background Music**: 
   - Add your background music file as `bg-music.mp3` or `bg-music.ogg`
   - Place it in the root directory of your website
   - **Important**: Make sure you have the rights to use the music

2. **Copyright-Free Music Sources**:
   - YouTube Audio Library (copyright-free)
   - Freesound.org
   - Zapsplat.com
   - Pixabay Music

3. **Current Setup**:
   - ✅ Mute button in top-left corner
   - ✅ Tick sound effects during loading (generated programmatically)
   - ✅ Background music player (waiting for audio file)
   - ✅ Volume control and user interaction handling

4. **File Formats Supported**:
   - MP3 (recommended for compatibility)
   - OGG (fallback for some browsers)

Note: The audio system is ready but needs the actual audio files to work.
